# 波波 AI 画布架构

## 定位

波波 AI 画布（Bobo AI Canvas）把 **Agent 对话**作为创作入口，把 **画布**作为上下文、过程和交付物的可编辑工作区。项目采用 Web 优先、客户端可打包的形态；当前代码仍包含本地优先运行模式，商业版本将把远端服务提升为正式数据源。

## 分层结构

```text
用户目标 / 参考素材
        │
        ▼
波波创作 Agent（对话、澄清、提案、技能路由、权限确认）
        │
        ├── 提示词中心：反推、优化、版本、模型适配
        ├── 媒体工作流：生图、生视频、图片细化、音频与剪辑
        ├── 画布工作区：节点、连线、便签、版本、撤销与恢复
        └── 内置 Skill：受控工具、版本固定、调用审计
        │
        ▼
任务与生成领域（排队、进度、失败、重试、结果入库）
        │
        ├── 当前 Web MVP：浏览器 + 本地工作区/测试后端
        └── 商业化目标：账号/租户、远端项目、对象存储、计费账本
```

## 运行边界

### Web MVP

- `web/` 提供 React、Vite、TypeScript 工作区和路由。
- `backend/` 提供 Go API、本地资源、任务、模型渠道和兼容协议。
- `agent-host/` 提供 Agent 会话宿主、Durable 会话恢复和受控工具桥。
- `plugin-packages/` 提供声明式模型/媒体渠道协议包。
- 浏览器缓存用于性能、草稿和失败恢复；在本地模式下 SQLite/本地资源仍是运行时存储。

### 商业化客户端

- Web 与桌面包共用版本化 API，客户端不内置供应商密钥或可信计费逻辑。
- 账号、租户、项目、画布修订、对话、素材、任务、Skill 版本和账单以远端服务为准。
- 对象存储保存原始素材、生成产物和恢复文件；客户端只保留可清理缓存、离线草稿和待同步队列。
- 任务服务通过幂等键、状态机和回调支持长时生图/生视频；关闭客户端后仍可查询任务。

## 关键数据流

1. 用户输入目标或选择场景，Agent 读取当前项目、画布和用户主动附加的素材。
2. Agent 澄清缺失信息，按需加载提示词反推、提示词优化或图片细化 Skill。
3. Agent 生成可检查的提案，列出提示词、模型、参考素材、产物和预计费用。
4. 用户编辑或确认提案；只有确认后才创建可能计费的生成任务。
5. 任务状态和结果写入项目/画布版本，源图与细化结果保持可追溯关系。
6. 服务端保存正式版本；客户端在断网、失败或冲突时保留草稿并要求用户选择恢复路径。

## 设计约束

- Agent 不绕过用户确认、权限校验和计费预占。
- Skill 只能通过受控工具读写允许的画布范围，不能执行任意脚本。
- 提示词反推和优化默认产生候选版本，不覆盖用户原文。
- 图片细化保留源图；插值放大必须和真实 AI 细节增强使用不同能力名称。
- 历史 `BeefAPI`、`.beeftv-plugin`、`HUABU_*` 等标识属于兼容协议或存储迁移边界，不能因品牌改名直接删除；详见[迁移说明](bobo-ai-canvas-migration-notes.md)。

## 当前实现状态

| 层 | 当前状态 | 发布判断 |
| --- | --- | --- |
| 品牌、首页和基础画布 | 已有实现依据并已统一波波 AI 画布文案 | 可进入 Web MVP 回归 |
| Agent 对话与内置 Skill | 会话宿主、技能加载和提案入口已有实现依据 | 需真实模型配置与权限回归 |
| 反推、优化、图片细化 | 前端入口、候选回填和局部编辑边界已有 | 真实视觉模型端到端待验收 |
| 生图/生视频任务 | 任务、渠道和结果入库已有 | 需按供应商逐项验收，不宣称全渠道可用 |
| 远端账号、同步和计费 | 目标架构 | 不属于当前本地 Web MVP |
