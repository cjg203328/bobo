# 波波 AI 画布架构

## 定位

波波 AI 画布（Bobo AI Canvas）把 **Agent 对话**作为创作入口，把 **画布**作为上下文、过程和交付物的可编辑工作区。项目采用 Web 优先、客户端可打包的形态；本地 profile 服务桌面单机使用，cloud profile 负责远端内部试用与后续商业数据面。

## 分层结构

```text
用户目标 / 类型化参考素材
        │
        ▼
波波创作 Agent（对话、澄清、提案、技能路由、权限确认）
        │
        ├── 场景合同：brief、输入/输出 Schema、参考位、交付与验收规则
        ├── 提示词中心：反推、优化、版本、模型适配
        ├── 媒体工作流：生图、生视频、图片细化、音频与剪辑
        ├── 画布工作区：节点、连线、便签、版本、撤销与恢复
        └── Skill / 工具包：多入口发现、受控执行、版本固定、调用审计
        │
        ▼
任务与生成领域（能力路由、报价、排队、进度、失败、重试、结果入库）
        │
        ├── 当前 cloud profile：PostgreSQL + 账号/个人空间 + 用户归属画布/素材 API
        ├── 内部试用边界：素材落后端持久卷；尚无对象存储、Agent 云端任务和商业账务
        └── 商业化目标：远端对象存储、持久任务、报价与计费账本
```

## 运行边界

### Web MVP

- `web/` 提供 React、Vite、TypeScript 工作区和路由。
- `backend/` 提供 Go API、本地资源、任务、模型渠道和兼容协议。
- `agent-host/` 提供 Agent 会话宿主、Durable 会话恢复和受控工具桥。
- `plugin-packages/` 提供声明式模型/媒体渠道协议包。
- 浏览器缓存用于性能、草稿和失败恢复；在本地模式下 SQLite/本地资源仍是运行时存储。

### 远端内部试用

- `cloud` profile 强制使用 PostgreSQL，并在注册时创建个人租户与所有者成员；会话凭据以 HttpOnly Cookie 传输，写请求校验 CSRF。
- 云端工作区 bootstrap、画布/项目和素材 API 根据已验证会话确定用户归属；客户端传入的 `userId` 不作为授权依据。
- 画布写入使用修订号和现有冲突保护；跨设备恢复以服务端项目与资源记录为准。
- 当前素材文件写入后端持久卷，Compose 和真实双浏览器尚未验收；该方式只适合单实例内部试用，后续改对象存储签名直传并补备份/恢复。
- 远端 profile 暂不开放模型调用、Agent 运行与计费，避免在任务和供应商结算合同完成前产生不可对账的远端生成。

### 商业化客户端

- Web 与桌面包共用版本化 API，客户端不内置供应商密钥或可信计费逻辑。
- 账号、租户、项目、画布修订、对话、素材、任务、Skill 版本和账单以远端服务为准。
- 对象存储保存原始素材、生成产物和恢复文件；客户端只保留可清理缓存、离线草稿和待同步队列。
- 云端资源上传采用短时签名直传和服务端完成登记；本地版本的 multipart/分片接收不视为该能力已实现。
- 任务服务通过幂等键、状态机和回调支持长时生图/生视频；关闭客户端后仍可查询任务。

## 关键数据流

1. 用户输入目标或选择场景，Agent 读取当前项目、画布和用户主动附加的素材。
2. Agent 澄清缺失信息，按场景/技能输入合同收集具名参考位，并按权限加载提示词反推、提示词优化或图片细化 Skill。
3. 服务端能力目录校验输入后选择符合条件的逻辑模型线路，生成绑定模型、供应商和价格版本的可检查提案/报价。
4. 用户编辑或确认提案；只有确认有效报价后才预占额度并幂等创建可能计费的生成任务。
5. 任务状态和结果写入项目/画布版本，源图与细化结果保持可追溯关系。
6. 服务端保存正式版本；客户端在断网、失败或冲突时保留草稿并要求用户选择恢复路径。

## API 与事件合同

远端 API 版本、身份与租户校验、幂等键、画布 CAS、Agent run、持久任务、账务账本及 outbox 事件 envelope 统一约束见[远端创作 API 与事件合同](remote-creative-api-contracts.md)。该文档区分当前内部试用接口和后续商业化合同；Agent 云端运行、任务队列和账务在实现并按真实流程验收前保持关闭。

## 设计约束

- Agent 不绕过用户确认、权限校验和计费预占。
- 类型化参考位和能力目录约束模型实际接收的输入；路由改变供应商、成本或隐私边界时重新报价并征得确认。
- Skill 只能通过受控工具读写允许的画布范围，不能执行任意脚本。
- 同一技能版本可通过对话、工具箱或画布入口发现；入口不得改变技能版本、权限或输入合同。
- 提示词反推和优化默认产生候选版本，不覆盖用户原文。
- 图片细化保留源图；插值放大必须和真实 AI 细节增强使用不同能力名称。
- 历史 `BeefAPI`、`.beeftv-plugin`、`HUABU_*` 等标识属于兼容协议或存储迁移边界，不能因品牌改名直接删除；详见[迁移说明](bobo-ai-canvas-migration-notes.md)。
