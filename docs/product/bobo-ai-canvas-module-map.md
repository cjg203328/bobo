# 波波 AI 画布模块地图与验收边界

## 产品模块

| 模块 | 用户价值 | 主要代码区域 | MVP 验收重点 |
| --- | --- | --- | --- |
| Agent 对话 | 用自然语言描述目标，获得澄清、方案和后续操作 | `web/src/pages/canvas`、`agent-host`、`backend/internal/agentops` | 多轮消息、附件/画布引用、提案确认、失败恢复 |
| 场景与创作合同 | 把业务目标映射为表单、参考素材角色、产物和验收约束 | 规划中的 `creation-contracts`；当前分散于 `web/src/lib/canvas`、`web/src/services/api` 和 `backend/internal/generation` | 输入/输出 Schema 固定版本；首发场景必填参考位能在创建任务前校验 |
| 提示词中心 | 反推、优化、比较和管理提示词版本 | `web/src/pages/canvas`、`web/src/lib`、`backend/internal/agentops` | 不覆盖原文、可编辑、可采纳、无模型时给出原因 |
| 图片生成 | 从文字、参考图和画布上下文生成图片 | `web/src/services`、`backend/internal/generation`、`backend/internal/provider` | 任务状态、参考素材、结果入库和重试 |
| 视频生成 | 从创意、分镜或首帧生成视频 | `web/src/services`、`backend/internal/generation` | 长任务、取消、进度、失败和结果回填 |
| 图片细化 | 全图衍生、局部蒙版、表情/材质调整和尺寸处理 | `web/src/components/canvas`、`web/src/lib/canvas` | 源图保留；不支持蒙版的模型拒绝执行 |
| 画布 | 组织便签、文本、图片、视频、音频和生成节点 | `web/src/components/canvas`、`web/src/stores/canvas`、`web/src/lib/canvas` | 移动、连线避障、便签保存、撤销/重做、恢复 |
| Skill 与工具包 | 在 Agent、工具箱和画布入口复用同一受控版本 | `agent-host`、`backend/internal/skills`、`plugin-packages`、`web/src/pages/skills` | 个人技能页不展示公共市场；保留本地包安装/文件/版本；旧发布 API 暂作兼容；补入口元数据和结构化输入 |
| 类型化参考位 | 将素材绑定到商品、角色、声音等业务角色 | 当前资源引用/角色/媒体能力分散在 `web/src/lib/canvas` 与生成配置；统一合同待建 | 媒体类型、资源类型、必填/数量/顺序约束；越权或不兼容在提交前拒绝 |
| 模型能力与路由 | 按能力和输入条件选择逻辑模型/供应商线路 | `backend/internal/modelcatalog`、`backend/internal/provider`、`web/src/lib/model-capabilities.ts` | 路由候选满足全部合同；线路变化可解释，影响价格时必须重报价 |
| 项目与素材 | 保存项目、参考素材、生成结果和引用关系 | `backend/internal/project`、`backend/internal/asset`、对应前端页面 | 当前本地归属校验/上传回执/删除保护；商业版签名直传、跨设备恢复和云权限另验 |
| 任务与报价 | 提交生成任务并保持费用、供应商状态和交付可追溯 | `backend/internal/creation`、`backend/internal/task`、`backend/internal/generation` | 区分配置预检与用户报价；商业链路验报价版本、幂等、未知状态查询、结算/退款 |
| 远端商业化 | 跨设备访问、套餐、额度、账单和审计 | 规划中的远端服务 | 账号隔离、签名上传、预占/结算/退款、导出删除 |
| 社区与联盟扩展 | 让用户授权分享可复用创作流程，或验证合作获客 | 暂无对应产品模块 | 独立验证授权、内容审核、反作弊、归因和结算；不纳入 MVP |

## 验收分层

### P0：Web MVP 必须通过

- 首页只展示波波 AI 画布及其 Agent 创作入口。
- 从一句话或场景卡进入对话，能附加参考并形成可编辑提案。
- 至少一个首发场景使用类型化参考位；缺少必填素材、超过数量上限、资源类型不符或越权引用时，在任务创建前给出明确原因。
- 反推、优化、图片细化都有明确的输入、候选结果和用户采纳动作。
- 画布便签编辑、撤销/重做、保存、失败草稿和重开恢复可验证。
- 生成任务必须经过确认，状态和失败原因可见。

### P1：打包客户端前必须通过

- 原生关窗保存、失败草稿和重开恢复。
- 任务在客户端关闭后继续运行，重新打开可读服务端状态。
- 技能入口、模型配置、渠道连接和本地兼容协议回归。
- 云端对象存储签名上传、完成回执、资源归属和断点恢复通过跨用户/租户测试。
- 商业报价服务端生成并绑定能力/线路/价格版本；报价确认、额度预占、任务提交、账本结算与退款可完整对账。
- 安装包、升级和数据目录迁移不再出现旧品牌公开文案。

### P2：商业化版本

- 远端项目/画布版本、对象存储、账号/租户权限。
- 套餐与操作报价、额度预占、成功结算、失败退款和账单明细。
- 团队协作、审批、共享 Skill 和实时协同画布。
- 公开作品发现/复制、品牌站和联盟分销须经独立商业验证，不作为商业化首版的默认范围。

## 证据规则

文档中“已有实现依据”表示代码、测试或接口合同可定位；只有通过对应场景的真实回归后，才能标记为“已验收”。供应商目录存在不代表真实模型可用，局部测试通过也不能替代端到端验收。
