## 一、产品定义（v2 收敛）

**一句话**：bobo 画布上的「电商内容技能市场」——卖家说一句话，得到可直接发布到小红书/拼多多/抖音/TikTok 的图文与视频物料。

**核心闭环**（复刻 justailab 内核）：

```
技能市场（分发）× 触发式路由（调用）× 生成闭环（出物料）× 画布承载（bobo 差异点）
```

**平台 × 内容矩阵**（P3 场景包的设计网格）：

| 平台 | 主内容类型 | 比例 | 语言 | 文案风格基线 |
|---|---|---|---|---|
| 小红书 | 种草图文（封面+多图详情+正文+标签） | 3:4 | 中文 | 第一人称碎碎念、软广自然感、Zakka 场景 |
| 拼多多 | 商品详情图/促销清单图文 | 1:1 / 3:4 | 中文 | 卖点直给、价格锚点、囤货引导 |
| 抖音 | 短视频脚本/封面/剧情带货分镜 | 9:16 | 中文 | 前 3 秒钩子、反转节奏、口播友好 |
| TikTok（跨境） | 上述任一类型的英文版 | 9:16 / 3:4 | **英文** | native speaker 口语、本地化表达 |

## 二、分期路线（P0-P4，每期有验收标准）

### P0 · 市场层最小闭环（3 天）

| 任务 | 改动点 |
|---|---|
| Skill 模型加 `UsageCount`/`LastUsedAt`/`IsFeatured`/`AuthorType` | `backend/internal/skills/skills.go`、`model/models_platform.go` + 迁移 |
| skill_load 成功回执埋点递增 | skills handler |
| 市场卡片展示「自动触发/仅手动」+「最多使用」排序 | `web/src/pages/skills/index.tsx` |

**验收**：市场页显示使用量；用技能后 +1；按使用量排序正确。

### P1 · 触发式路由（3 天）

| 任务 | 改动点 |
|---|---|
| SKILL.md description 三段式规范（触发条件/产出形态/风格约束）+ 校验 | 技能导入/创建校验 |
| 助手「自动路由」开关（justailab `runtime_skill_recommend` 对应物） | 助手侧栏 + 偏好存储 |
| 服务端路由端点：请求带技能目录摘要 → 返回命中 skill_id 集合 | 新端点（v1 规则/LLM 分类） |

**验收**：写「当你提供商品信息时，调用该技能，生成小红书种草图文」技能，开开关后输入「帮我推这款 new 保温杯」自动挂载。

### P2 · 表单工作流（4 天）

| 任务 | 改动点 |
|---|---|
| 场景模板数据模型（form JSON + 预填 prompt + category + 可选 reply） | 本地配置表/JSON 种子 |
| 创作台「场景」面板：模板 → 渲染表单 → 发起 | `web/src/pages/create/` |
| 本地 JSON 热更新（改配置即生效，对应 justailab 服务端热配置） | 配置读取层 |
| **首批 5 个电商场景模板**（仿 justailab marketing_form） | 种子数据 |

**首批场景模板**（电商化）：

| 模板 | 表单字段 | 预填 prompt |
|---|---|---|
| 商品种草图文 | 商品名/卖点/目标人群/平台/风格 | 「帮我做一篇小红书商品种草图文」 |
| 爆款封面 | 主题/平台/标题文案/风格/尺寸/素材 | 先回素材收集话术再生成 |
| 直播口播稿 | 商品/价格机制/福利/时长 | 「写一场 30 分钟直播口播稿」 |
| 商品详情页 | 商品图/参数/场景/竞品差异 | 「生成商品详情页图文」 |
| 促销活动清单 | 商品/折扣/截止时间/人群 | 「做一张促销清单图文」 |

**验收**：填表单 → 自动拼 prompt → 助手产出；改 JSON 加新场景不发版。

## 三、明确不复刻（8 项）

支付/订单/卡券 · 裂变解锁 · 创作者分成结算 · 微信小程序/iOS App · 团队额度共享 · 内容监控 · 定时任务/内容日历 · 第三方监控统计。

理由：个人开发者不可承受或与「本地优先 + 自用」定位冲突（justailab 自身结算体系亦未全量上线）。

## 四、差异化定位

| 维度 | justailab | bobo 复刻版 |
|---|---|---|
| 承载 | 对话流聊完即走 | **画布节点**：物料可再编排、批量管理 |
| 技能格式 | frontmatter 不解析/references 不递归/同名即失败 | 三层全支持（已实现） |
| 数据 | 全云端 | 本地优先 |
| 工作流 | 服务端热配置 | 本地 JSON 配置 |
| 场景 | 通用内容营销 | **电商四平台矩阵**（更垂直，卖家付费意愿更强） |

定位语：**「justailab 的技能市场 × bobo 的画布，为电商卖家而生」——技能是弹药，画布是战场。**
