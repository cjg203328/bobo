# 波波 AI 画布文档

波波 AI 画布（Bobo AI Canvas）是一个由 Agent 驱动的视觉创作工作台。用户可以通过对话或画布完成提示词、图片、视频和项目编排；Web MVP 优先验证创作闭环，远端服务负责后续商业化数据与计费。
